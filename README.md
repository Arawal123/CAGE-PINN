# CAGE-PINN

**Cross-fitted Audit-Guided Enforcement for Compute-Budgeted Generalization in
Physics-Informed Neural Networks**

CAGE-PINN is a research implementation for testing one precise question:
can unseen, off-grid physics violations—without reference-solution access—detect
collocation overfitting and allocate a fixed physics-compute budget among fresh
strong-form points (S), residual-input slope regularization (J), and stochastic
multi-scale weak witnesses (W)?

This repository is experimental infrastructure, not evidence that the method is
better than existing PINNs. The novelty gate is **provisional**. The July 2026
search found substantial component overlap with gPINN, residual-overfitting
regularization, RoPINN, PINNACLE, weak/variational PINNs, error certification,
and gradient-conflict methods. It did not verify the exact CAGE combination, but
the corpus is intentionally labeled non-exhaustive and needs independent review
before publication.

## What is implemented

- JAX/Equinox vanilla, XPINN, and adaptive-basis backbones through one interface.
- Strict learner/selector/monitor/calibration separation with coordinate hashes,
  rotation, refresh, and leakage checks.
- Stop-gradient residual-channel scale tracking.
- Empirical CVaR and a conservative, fixed-schedule, union-corrected upper bound
  for bounded residual scores. This is **not** a solution-error certificate.
- S, J, and W enforcement atoms with applicability checks and explicit costs.
- Exact and Rademacher-sketch audit-gradient utility.
- Entropy/exploration-aware, capped-simplex allocation and exact token rounding.
- Symbolic and measured compute ledger; CAGE audit overhead is charged.
- Immutable run records, manifests, freeze hashes, paired analysis, figures, and
  claim-evidence checks.
- Analytic smoke PDEs and a declarative discovery/confirmatory benchmark registry.

High-cost external baselines are represented by explicit, license-aware adapters.
An unavailable official dependency raises an error; there is no silent fallback.
The core includes native vanilla, uniform-resampling, RAR-D, gPINN, static S/J/W,
ReLoBRaLo-style weighting, SA-style weighting, and ConFIG-style two-loss gradient
composition. Publication comparisons still require official-repository fidelity
checks recorded in `docs/baseline_fidelity.md`.

```bash

python -m pip install --upgrade pip
```


## Workflow

```bash
python -m cage_pinn.cli literature build
python -m cage_pinn.cli novelty audit
python -m cage_pinn.cli benchmark list
python -m cage_pinn.cli benchmark verify-references
python -m cage_pinn.cli budget calibrate --repeats 5
python -m cage_pinn.cli study smoke --steps 8
python -m cage_pinn.cli study discovery --manifest experiments/manifests/discovery.yaml
python -m cage_pinn.cli study freeze --manifest experiments/manifests/confirmatory.yaml
python -m cage_pinn.cli study confirmatory --manifest <FROZEN_MANIFEST>
python -m cage_pinn.cli analyze confirmatory
python -m cage_pinn.cli report build
```

Raw records are append-only JSON files under `results/raw/`. Processed tables and
figures are regenerated under `results/processed/` and `results/figures/`.

## Extension points

- Add a PDE by subclassing `PDEProblem`, defining residual channels, domain,
  boundary loss, and an independently checked reference.
- Add an atom by implementing the `EnforcementAtom` protocol and registering its
  applicability and cost.
- Add a backbone by implementing call, interface loss, parameter count, and audit
  strata. CAGE never changes the parent architecture or parameter budget.
- Audit a run with `python -m cage_pinn.cli audit run PATH_TO_JSON`.

## Scope and limitations

The checked-in smoke references are analytic. Large CFD references, official
baseline reproductions, GPU calibration, and confirmatory statistics are not
fabricated and are not bundled as completed results. Cavity, chaotic, sharp
conservation-law, and high-dimensional runs need substantial compute and reference
validation before any numerical claim is supportable. See `docs/`.
